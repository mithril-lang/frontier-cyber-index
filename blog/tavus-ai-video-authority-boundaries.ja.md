# AI動画と声のなりすまし：Tavusから考える権限の境界

2026-10-07。公開一次資料に基づく調査。特定提供者への不正や脆弱性の告発ではありません。

ビデオ通話で顔が見え、聞き慣れた声で話しかけられても、送金や資料送付を承認した本人かは
別に確認する必要があります。リアルタイムのAI動画と音声に、文書検索や業務toolが加わると、
会話の自然さが操作権限に取り違えられる場面が生まれます。Mithrilは、提供者の機能説明、
観測された悪用、導入側で備えるべき境界を分けて整理しました。

## Tavusについて確認できたこと

Tavusは、Phoenix-4.5の描画、Raven-1の音声・映像知覚、Sparrow-2の対話の流れを説明しています。
提供者の[Engineering資料](https://github.com/Tavus-Engineering/tavus-intake/blob/main/docs/tavus-features.md)
には、対話中にpersonaのtool callを扱う構成例があります。[製品説明](https://www.tavus.io/)
を確認しましたが、Mithrilは性能や感情推定の精度を実測していません。

[利用ポリシー](https://www.tavus.io/acceptable-use-policy)は2026-04-14発効と表示され、
本人の明示的同意、AIであることの開示、同意撤回の尊重等を要求しています。
この要件があることと、実際の阻止率がいくつかということは別です。
今回の調査はTavusの同意確認を突破したり、実人物を無断で複製したものではありません。

## 観測された悪用と提供者への帰属を分ける

FBI/IC3は2024年12月に、生成AIの音声や動画を使う金融詐欺を警告しました。
2025年5月の警告では、同年4月以降の米国高官へのなりすましでAI音声が使われたと説明しています。
どちらも一般的な悪用の報告で、Tavusが使われたとする証拠ではありません。
[FBIの生成AI詐欺警告](https://www.ic3.gov/PSA/2024/PSA241203)、
[高官へのなりすまし警告](https://www.ic3.gov/PSA/2025/PSA250515)。

最近の[Anthropicの2026年9月report](https://www.anthropic.com/threat-intelligence-report-september-2026)
も、cyber operationsや詐欺等のサービス悪用事例を扱います。対象期間は2025年12月から
2026年8月で、サービス提供者が観測した事例です。市場全体の頻度や、全モデルの能力を
この資料だけから推定しません。

## 見た目・本人確認・取引承認を分ける

次はMithrilの脅威分析です。動画や声を本人確認の唯一の根拠にすると、偽上司からの口座変更、
偽IT窓口からのMFA解除、偽担当者からの資料送付といった要求を認めてしまう可能性があります。
そこで確認するのは、登録済みの独立した連絡経路、認証されたprincipal、
そして「どの口座へいくら」「どの資料を誰へ」という具体的な操作の承認です。

| 境界 | 演習で確認すること |
| --- | --- |
| 顔・声 → 本人確認 | 類似して見えるだけで例外処理を許さない |
| 文書・会話 → tool | 不信な内容から権限を追加しない |
| 同意 → replica利用 | 用途・期限・撤回状態を確認する |
| 録画・知覚 → 保存 | 閲覧者と保持範囲を限定し、不確実な推定を断定しない |
| 承認 → 実行 | 承認内容と操作を照合し、拒否・通過の両方を記録する |

deepfake detectorの結果だけで本人を決めると、未知の生成方式や誤検知に対応できません。
来歴情報があることも、発言内容の真実や取引権限を保証しません。ないだけで偽物と断定することも
避けます。ログを読み返せることと、正常な業務を続けられることも同時に測る必要があります。

## 会話agentの安全性を業務で測る

[OWASPの2026年9月発表](https://genai.owasp.org/2026/09/01/owasp-genai-security-project-unveils-2026-top-10-for-llm-applications-new-agent-control-standard-and-sponsors-as-community-tops-30000-members/)
は、LLM Top10新版とAgent Control Standard等を案内しています。
Mithrilはこうした参照軸を使い、promptの注意書きに加えて、実行側の権限境界と
正常業務の完了を評価する計画です。

公開した[演習教材](https://github.com/mithril-lang/frontier-cyber-index/tree/main/exercises)では、
音声で要求された口座変更、同意撤回後の素材利用、不信文書からのtool権限変更を合成証拠で扱います。
全て架空の入力で、実人物の映像も送金も必要ありません。これは入門教材で、Tavusの対策や
frontier modelの性能を認定するものではありません。

[調査レポートと出典台帳](https://github.com/mithril-lang/frontier-cyber-index/tree/main/reports)を読み、
自分の業務でどこが本人確認、どこが操作の承認、どこが同意撤回の確認になっているかを整理してください。
Mithrilの実測値は今後、独立した採点器と非公開課題を整えてから公開します。
